# pet-art — 캐릭터 옆 펫

아바타 꾸미기 상점의 `pet` 아이템 그림. 펫 4종 × 자라는 3단계 = 12장, 코드로 그린 SVG를 WebP(투명)로 구워서 두 앱에 넣는다.

| id | 펫 | 꼬마(7일~) | 다 큼(30일~) |
|---|---|---|---|
| pet_jindo | 진돗개 | 빨간 목줄 + 금 이름표 | 태극색 반다나 |
| pet_hangulmon | 미니 한글몬 | 연필 | "한글" 책 |
| pet_tiger | 아기 호랑이 | 빨간 목줄 | 색동 목도리 |
| pet_dokkaebi | 도깨비 | 뿔 하나 + 나무 방망이 | 뿔 둘 + 금 방망이 |

- 아기(0~6일)는 머리 크고 동글, 장식 없음. 연속이 끊기면 다시 아기 — 단계는 앱이 streak 로 정한다 (서버는 id 만).
- 캔버스 400×400, 발은 y≈384, 정면. 움직이지 않는다.
- 간판 글자는 `../scene-art/glyphs.json` (Jua) — "한글" 포함.
- 굽기: 루트에서 `npx tsx tools/pet-art/render.ts`
